📱 Als App installieren

Die Seite kann wie eine echte App aufs Handy oder den PC – mit eigenem Icon im Vollbild.

📱 Android (Chrome / Edge)

  1. Tippe oben rechts auf das ⋮ Menü
  2. Wähle „App installieren"
  3. Bestätigen → 🛒 Icon auf dem Startbildschirm

🍎 iPhone (Safari)

  1. Tippe unten auf das Teilen-Symbol
  2. Wähle „Zum Home-Bildschirm hinzufügen"

💻 Desktop (Chrome / Edge)

  1. In der Adressleiste rechts: Install-Icon klicken
  2. App wird wie normales Programm installiert

⚙️ Technik

  • Alle 10 Min läuft GitHub Actions
  • Änderungen werden direkt zu GitHub gepusht (siehe Commit-Historie)
  • Diese App ist eine statische Single-Page-App auf GitHub Pages – kein Server, kein Schlafen

🔑 GitHub-Token

Die App benötigt einen GitHub Personal Access Token mit repo Berechtigung um Monitore zu speichern.
